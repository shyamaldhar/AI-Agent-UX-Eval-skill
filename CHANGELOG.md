# Changelog

All notable changes to this framework will be documented here.

## v1.0.0 — Initial Release

- Three-layer Agent UX Evaluation Framework: Design Intent (4 principles), Experience Dimensions (21 dimensions across 4 pillars), Experience Quality (14 signals across Trust, Momentum, Sentiment)
- Claude Skill implementation with guided step-by-step evaluation workflow
- Support for Chrome-extension capture, URL fetch, screenshot walkthrough, and pasted-text input methods
- Conservative-by-default scoring rubric with mandatory step references and fix paths for every finding
- Optional agent-type weighting across four archetypes: Conversational, Data, Workflow, Insight
- Structured `.docx` report generation
